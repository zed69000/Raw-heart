# Raw Heart

Prototype jouable (Déni et Tristesse), à ouvrir dans un navigateur.

- Ordinateur : clavier et souris, casque recommandé.
- Téléphone : à l'horizontale ; le bouton Plein écran du titre masque les barres du navigateur. Sur Android et iPhone, « Ajouter à l'écran d'accueil » l'ouvre directement en plein écran.
